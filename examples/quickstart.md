# 一次从建档到润色的试用

以下人物、表达和文章均为虚构，来自 2026-11-09 的实际代理试用。展示使用方式，不代表真实用户已经认可相似度。

## 方式一：先聊一件事

使用者：“我是小学老师，写给年轻老师看，不想被写成训人的专家。没有现成文章，你可以问我。”

Skill 的第一问：

> 最近工作中，有没有一件你想讲给年轻老师听的小事？按你平时聊天的方式说说就好。

使用者自然回答：“我一般先让他们把想说的讲出来，顺了再落到纸上。写给年轻老师时也一样，我愿意讲怎么试，不想上来就评价谁对谁错。我的学校和学生信息都别写。”

试用中保存的 teacher 档案摘录：

| 内容 | 记录方式 |
| --- | --- |
| 教师身份 | 自述背景；给年轻老师写作时以同行身份交流 |
| “愿意讲怎么试，不想上来就评价” | 明确偏好；先解释做法，少抢着下判断 |
| “讲出来，顺了再落到纸上” | 单次观察；可尝试按动作顺序展开 |
| 学校与学生信息 | 只记录抽象不公开规则，不要求提供具体身份 |
| 完成状态 | 初步／待校准，未冒充已获本人认可 |

## 方式二：直接给过往内容

另一位使用者以普通工具使用者身份给 AI 新手写内容，提供三段本人原作，包括：

> 先把一件小事说明白，反而容易做下去。

> 这个功能我还没试完，先说目前看到的。

> 比如整理资料，先说文件放哪、下次怎么找。

同时明确：不公开公司、职务、收入，不写没发生过的亲测。

试用中建立 tool-user 档案，把具体动作、短句和已知／未知的区分记录为有场景范围的观察。三段文章充分时没有重新访谈；档案实际保存后再次读取，用于后续修改。

待改稿：

> 在人工智能浪潮席卷而来的今天，这款工具不仅重塑知识管理的边界，更为个人效率赋能。它可以按标签筛选笔记。离线搜索计划下个月上线，目前还没有完成测试。

实际润色结果：

> 这款工具可以按标签筛选笔记。离线搜索计划下个月上线，目前还没有完成测试。

句子已经能说清的部分可以少改。没有为了“有个性”加入身份、亲测、效果数字或样本里的建议，也没有把计划写成已上线。

## 外部文章与个人边界

使用者提供另一位作者的经历，要求按自己的风格整理。原文包含使用 30 天、处理 200 份记录，以及离线搜索尚未发布；同时提供一段仅供理解、不可公开的个人经历。

实际改写：

> 原作者说，自己连续用了这款工具 30 天，处理了 200 份记录。工具支持按标签筛选笔记，离线搜索还在测试，尚未发布。原作者认为，这种整理方式值得试一试。

保留数字及外部作者归因，个人私密经历没有进入成稿。后续仅针对一篇的“先看看改成先确认”要求，也未被升级为长期规则。

## 换一个会话，读档案继续用

随后用新的代理上下文实际读取已保存的 tool-user 档案，对一段新的功能说明进行润色，没有重新采访。

原文：

> 整理资料时，可以先为笔记设置标签，再按标签筛选。本地搜索目前只能查找标题，还不能检索附件内容。全文搜索计划下个月开始测试，是否上线尚未确定。

tool-user 档案的实际输出：

> 整理资料时，可以先给笔记加上标签，再按标签筛选。
>
> 本地搜索目前只能查标题，还查不到附件里的内容。全文搜索计划下个月开始测试，是否上线还没确定。

另一位虚构使用者明确希望“连贯书面段落、适度复句、面向同行、不劝导读者”，据此建立 editor 档案；没有原作，所以档案只标为明确的目标偏好。相同原文的实际输出：

> 整理资料时，可以先为笔记设置标签，再通过标签筛选资料；本地搜索目前则仅支持标题查找，尚不能检索附件内容。全文搜索计划于下个月开始测试，是否上线仍未确定。

两版的词语和段落组织有区别，功能与限制保持一致。这个差异来自档案里的表达依据和明确偏好，不是“编辑身份就应该这样说”的推断，也不代表已证明真人相似度。

当用户新增“不评价同业公司的经营能力”的长期边界，却同时要求润色一篇以该评价为核心的文章时，试用中只询问这篇是否临时放开边界，没有擅自改结论或放开长期规则。

## 自己开始使用

安装后说：“请用 personal-voice-polisher，先从一个具体问题了解我的表达；我也会提供几段自己的文章。先建立待校准档案，再拿一小段试改给我看。”

样本不足、场景变化大或原稿本来很自然时，改写幅度可能较小。哪一句像或不像，需要你指出具体位置，才能继续校准。
